# RTL Modifications & Verification Guidelines

---

## Code Fixes & Linting Rules

### 1. Register Initializations

Removed register initializations at the start and added value assignments in the reset block.

```verilog
// reg [2:0] a = 3'd5; is illegal --> 

reg a;
.
.
.
if (sys_rst) begin
    . 
    .
    a <= 3'd5; // (or zero if there is no initialization - to prevent X propagation)
    .
    .
end

```

---

### 2. X-Propagation Prevention

Ensure all the registers are assigned either zero or a constant value (as generated by LiteX) to prevent X propagation.

---

### 3. Initial Blocks

Remove all `initial` blocks.

---

### 4. Memory Assignments

Any `readmemh` assignments can be replaced with constant assignments in a combinational block.

**Example:**

```verilog
reg [7:0] mem[0:41];

// Identifier:
always @(*) begin
    mem[0] = 8'h50; mem[1] = 8'h49; mem[2] = 8'h43; mem[3] = 8'h4F; mem[4] = 8'h52; mem[5] = 8'h56; mem[6] = 8'h33; mem[7] = 8'h32; // PICORV32
    mem[8] = 8'h20; mem[9] = 8'h42; mem[10]= 8'h41; mem[11]= 8'h53; mem[12]= 8'h45; mem[13]= 8'h44; mem[14]= 8'h20;                 // BASED
    mem[15]= 8'h4D; mem[16]= 8'h43; mem[17]= 8'h55; mem[18]= 8'h20; mem[19]= 8'h49; mem[20]= 8'h49; mem[21]= 8'h54;                 // MCU IIT
    mem[22]= 8'h47; mem[23]= 8'h4E; mem[24]= 8'h20; mem[25]= 8'h50; mem[26]= 8'h52; mem[27]= 8'h4F; mem[28]= 8'h4A;                 // GN PROJ
    mem[29]= 8'h45; mem[30]= 8'h43; mem[31]= 8'h54; mem[32]= 8'h20; mem[33]= 8'h4D; mem[34]= 8'h41; mem[35]= 8'h44;                 // ECT MAD
    mem[36]= 8'h48; mem[37]= 8'h41; mem[38]= 8'h56; mem[39]= 8'h41; mem[40]= 8'h00; mem[41]= 8'h00;                                 // HAVA + zero-pads
end

```

### 5. FSM Default Cases

Add default cases wherever missing in the FSMs that don't cover all cases.

**Example:**

```verilog
case (customasicsoc_last_sink_width)
    1'd1: begin
        customasicsoc_sr_in <= {customasicsoc_sr_in[30:0], customasicsoc_dq_i[1]};
    end
    2'd2: begin
        customasicsoc_sr_in <= {customasicsoc_sr_in[29:0], customasicsoc_dq_i};
    end
    3'd4: begin
        customasicsoc_sr_in <= {customasicsoc_sr_in[29:0], customasicsoc_dq_i};
    end
    4'd8: begin
        customasicsoc_sr_in <= {customasicsoc_sr_in[29:0], customasicsoc_dq_i};
    end
    default: customasicsoc_sr_in <= 32'd0; // Added a default case statement matching the reset value of the reg customasicsoc_sr_in.
endcase

```

---

### 6. SCL180 Memory Macros

For SCL180 Memory macros - Invert clock signals to the macros if there are any timing violation errors w.r.t. the `WEB` signal.

**Example:**

```verilog
SPRAM_8192x8 main_ram_spram (
    .A   (customasicsoc_customasicsoc_sram1_adr[12:0]),
    .CE  (~sys_clk), // Received a hold violation here. Now, WE signal is asserted at posedge and will be read by macro at negedge 
    .WEB (~customasicsoc_customasicsoc_sram1_we[main_ram_li]), // giving it more time to stabilize.
    .OEB (1'b0),
    .CSB (1'b0),
    .I   (customasicsoc_customasicsoc_sram1_dat_w[8*main_ram_li +: 8]),
    .O   (main_ram_dat_r_wire[8*main_ram_li +: 8])
);

```

### JasperGold SuperLint

#### Launch Instructions

1. Open JasperGold:
```bash
jaspergold -allow_unsupported_OS

```


2. Go to **View** Menu on the top bar $\rightarrow$ Select **Applications** $\rightarrow$ Select **Superlint**.
3. Run the following in the command line at the bottom:

#### Workflow Steps

* **Step 1: Analyze Files**
```tcl
analyze -v2k  \
        modified.v  \                                                 # List of files used
        picorv32.v \
        timer1.v  \
        /pdk/SCLPDK_V3.0_KIT/scl180/memory/spram/6M1L/SPRAM_1024x36/SPRAM_1024x36.v \      # List of foundry macros used 
        /pdk/SCLPDK_V3.0_KIT/scl180/memory/spram/6M1L/SPRAM_8192x8/SPRAM_8192x8.v \
        -bbox_m SPRAM_1024x36  \                                                            # List of Modules to be considered as blackboxes
        -bbox_m SPRAM_8192x8   \                                                            # Won't check linting for these modules
        -bbox_m timer1  \
        -bbox_m picorv32

```


* **Step 2: Rule Configuration**
```tcl
config_rtlds -rule -enable -category {BLACKBOX FILEFORMAT CODINGSTYLE SIM_SYNTH SYNTHESIS STRUCTURAL} 
// Can do the above through GUI as well to select more rules if needed

```


* **Step 3: Elaboration & Clock/Reset Setup**
```tcl
elaborate -top top     # Set the top module
clock clk              # Set the clock signal name in the design
reset rst              # Set the reset signal in the design

```


* **Step 4: Run Lint Checks**
*(Run these one after the other)*
```tcl
check_superlint -init
check_superlint -configure
check_superlint -extract
check_superlint -report -signoff # This gives a console output with total errors and warnings

```


* **Step 5: Debug & Fix**
In the **Violation Message View** above the console pane, expand the message tree to find Warnings and Errors $\rightarrow$ Fix them accordingly.

```bash

    +transport_path_delays \                                                    # Enables full transport delay modelling present in specify blocks without filtering

    picorv32.v \
    timer1.v \
    /pdk/SCLPDK_V3.0_KIT/scl180/memory/spram/6M1L/SPRAM_1024x36/SPRAM_1024x36.v \    # PDK macros location

    -top tb \                                                                   # Setting top module as the testbench (replace tb with testbench module name)
    -access +rwc \                                                              # Required: Access for xrun to the files
    -gui \                                                                      # GUI mode 
    -input restore.tcl                                                          # Can save the simulation configuration and restore it in the next run (e.g. Can restore the signals monitored in the Waveform view)
```
